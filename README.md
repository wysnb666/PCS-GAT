# PCS-GAT

PCS-GAT is a path-constrained selection framework for improving local decisions in graph optimization with path-structured solutions.

This repository contains the implementation of PCS-GAT and its instantiation on the MPC_v^{4+} approximation pipeline. PCS-GAT learns to rank legal local modification candidates generated by the original solver.

## Repository structure

- core/: graph utilities and basic data structures.
- phase1/--phase5/: implementation of the reproduced approximation pipeline.
- solver/: phase runners and solver interfaces.
- experiments/: dataset generation, training, evaluation, models, and baselines.
- tests/: tests and validation scripts.

## Environment

The experiments in the paper were conducted on a Linux server running Ubuntu 22.04.4 LTS with an AMD Ryzen Threadripper PRO 5975WX 32-Core CPU, 251 GiB RAM, and an NVIDIA RTX A6000 GPU with 49 GB memory.

The main software environment used:

- Python 3.10.20
- PyTorch 2.8.0
- XGBoost 2.1.4
- OR-Tools 9.15.6755

## Installation

Create and activate a conda environment with Python 3.10, then install the required packages:

conda create -n PCS python=3.10
conda activate PCS
pip install -r requirements.txt

## Quick check

Run the test suite with:

pytest tests

## Notes

This repository focuses on the source code and experimental scripts. Large generated artifacts, logs, model checkpoints, intermediate trace files, and generated datasets are not included in the repository.
